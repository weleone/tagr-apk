# tagr-apk

Tagr 的安卓 WebView 壳：手机上打开家里的 Tagr 服务器，远程改音乐标签。

> **需要搭配后台服务使用。** 这个 App 本身只是一个浏览器壳，不带 Tagr 服务、不存音乐、不改本地文件。必须先有一台跑着 Tagr 后台服务的机器（自建 Docker 部署，见下面），App 连上它才能用。没有后台服务，打开只能看到登录页或空白页。

- 当前版本：**v1.0.13**
- 包名：`com.weleone.tagr`
- 默认服务器：`http://192.168.1.3:8307`（A 机 Tagr）
- 顶部地址真正居中（点它也能换服务器），右侧只有 ⚙ 服务器管理；服务器列表每行有圆点选择当前服务器，右边显示连通性（绿 ✓ 通、红 × 不通），添加后立即检测；地址栏会跟随页面黑白主题变色；黑白切换用页面自带的按钮，原生 ◐ 按钮已去掉（重复了）
- 下拉刷新；返回键先回退网页历史
- 移动端布局（不强制桌面版）
- 不带下载功能，不带本地改标签（本地改标签不在这个 App 里做）

## 后台服务

Tagr 后台用 Docker 部署，汉化版镜像 `weleone/tagr-zh:1.17.1`（只留中英文），或上游 `suitux/tagr`。容器里要挂音乐目录（`/music`，读写，改标签会写回 MP3 文件），端口 `8307:3000`。先把后台跑起来、浏览器能打开 `http://服务器IP:8307` 并登录，再用这个 App 连。

## 下载

去 [Releases](https://github.com/weleone/tagr-apk/releases) 下最新版 APK（`tagr_v1.0.13.apk` 之类），直接安装。装好打开默认进上面写的服务器地址，点 ⚙ 可以换成你自己的。

构建走 GitHub Actions（`build-apk.yml`），产物是 debug APK（未正式签名）。

## 构建

推一个 `v*` tag 或在 Actions 里手动跑 `workflow_dispatch`，产物在 Artifacts 里（`tagr-apk`）。
